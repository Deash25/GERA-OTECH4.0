# Digital Store - Back-end API 🚀

API RESTful desenvolvida com Node.js e Express para a gestão de produtos do e-commerce Digital Store.

## 🛠️ Tecnologias Utilizadas

- **Node.js** & **Express**
- **SQLite** & **Prisma ORM**
- **Swagger UI** (Documentação interativa)
- Arquitetura **MVC** (Model-View-Controller)

## 📋 Requisitos Cumpridos

- [x] CRUD completo de produtos (`GET`, `POST`, `PUT`, `DELETE`)
- [x] Persistência de dados com Prisma ORM e SQLite
- [x] Padrão arquitetural MVC (Controllers, Routes, Config)
- [x] Documentação Swagger funcional em `/api-docs`
- [x] Tratamento de erros e respostas HTTP padronizadas
