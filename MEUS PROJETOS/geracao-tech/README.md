# Geração Tech 4.0 - Digital Store 🚀

Aplicação web e-commerce desenvolvida em React para o projeto final do curso Front-end da Geração Tech 4.0. O projeto combina um portfólio institucional com uma loja virtual de equipamentos tecnológicos consumindo a Fake Store API.

## 📋 Requisitos Cumpridos

- [x] **Aplicação React:** Componentização, rotas dinâmicas com `react-router-dom`, consumo de API via `axios` e otimização de carregamento com `lazy` e `Suspense`.
- [x] **Rotas Obrigatórias:**
  - Página Inicial (Home / Portfólio)
  - Página de Listagem de Produtos (`/store`)
  - Página de Detalhes do Produto (`/store/:id`)
- [x] **Interface e Design:** Layout Dark Tech responsivo utilizando a biblioteca de componentes **PrimeReact**.
- [x] **Recursos Visuais:** Controles de ordenação e filtros por categoria de equipamento.
- [x] **Funcionalidade Extra:** Formulário funcional para cadastro manual de novos equipamentos na vitrine.

## 🛠️ Tecnologias Utilizadas

- **React** (JavaScript)
- **Vite**
- **React Router Dom**
- **PrimeReact & PrimeFlex**
- **Axios** (Integração com Fake Store API)
